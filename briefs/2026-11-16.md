## 12. Deep dive: FBI FLASH 20261113-001, ARTEX autonomous pentest framework weaponised (13 Nov 2026, TLP:CLEAR) [NEW]

**Primary:** https://www.ic3.gov/CSA/2026/261113.pdf
**Context:** Microsoft Storm-0940 (21 Oct) https://www.microsoft.com/en-us/security/blog/2026/10/21/storm-0940-uses-artex-agentic-ai-connectwise-supply-chain-compromise/ ; Microsoft Storm-3358 (6 Nov) https://www.microsoft.com/en-us/security/blog/2026/11/06/artex-abuse-expands-as-cybercriminals-target-financial-sector/ ; The Record https://therecord.media/artex-ai-tool-fbi-flash-alert ; secondary summaries https://agentbeam.com/blog/fbi-flash-artex-autonomous-penetration-testing-framework-november-2026 and https://blog.senthorus.ch/posts/weekly_reviews/16_11_2026 ; Amazon and Barracuda (section 5).
ARTEX itself was in the 12 Nov brief (Unit 42). The FLASH is the first US government advisory on it.

### Why it matters for a global consulting firm
- **Legal is a named target sector,** with financial services, government, technology, defence, semiconductor, energy, healthcare, manufacturing and telecoms.
- **SaaS-to-tenant supply chain:** Storm-0940 used compromised ConnectWise Cloud Backup app identities, already consented in customer Entra tenants, to authenticate without user sign-in to more than 2,250 tenants. A consultancy consents to many multi-tenant apps.
- **Speed:** some intrusions reached privileged access in under three hours.
- **Periphery targeting:** partner portals, mobile backends, employee apps, legacy integrations, i.e. client-delivery and engagement portals.
- **Sanctioned AI use can mask attacker egress:** LLM API calls from servers are a signal.

### Attribution and confidence
- ARTEX is a dual-use open-source tool; the FLASH speaks of "threat actors" and gives no confidence levels.
- Korean financial campaign: financially motivated, unnamed.
- ConnectWise campaign: Microsoft's Storm-0940, "China-state aligned", active since 2021; Microsoft "assesses" responsibility, no confidence level. [CONFLICT, see corrections.]
- Storm-3358: Microsoft, "Cambodia-based", financially motivated, financial organisations mainly in South-East Asia.
- Developer: "Autumn-27", identified as Li Puhua per Censys/The Record.

### Timeline
- Jul 2026: ARTEX released on GitHub. Since at least Aug: malicious use (FBI). Early Sep: Storm-0940 adopts it (Microsoft).
- 8 Oct: original repo removed; forks, mirrors and a commercial "ARTEX PRO" continue.
- 10–14 Oct: spray from 144.172.64[.]99 against 327 accounts at 8 organisations, 151,000+ failed logons, no successes (Microsoft).
- 15–16 Oct: Graph API access through compromised apps from transient VPN IPs; ConnectWise advisory 16 Oct.
- Oct: Storm-3358 begins. 2 Nov: WISP C2 first seen; still active 6 Nov.
- Early Nov: more than 1,600 exposed ARTEX consoles. 13 Nov: FLASH.

### Attack chain
1. Natural-language objective broken into tasks for specialised agents; attacker instances mostly on DeepSeek "Flash" models; supports Claude, GPT, GLM, Grok, Kimi.
2. Recon: active scanning, cloud/permission/account discovery, ARM deployment-validation dry runs, CloudWatch `FilterLogEvents` secret searches.
3. Initial access: public-facing app exploits (Storm-3358: anonymous upload, SSRF), valid accounts and spraying, external remote services, supply chain / trusted relationship (ConnectWise), SAML token forgery, secrets in repos, CI/CD and IaC.
4. Persistence: .aspx/.jsp web shells; credentials added to existing OAuth apps; DLL hijacking; WISP, vshell, AdaptixC2.
5. Privilege escalation: Storm-0940 self-assigned Global Administrator from a ConnectWise app; token manipulation; metadata API; Kerberoasting; container API secrets.
6. Credential access / lateral: Key Vault secrets bulk-read across vaults; pass-the-ticket/hash; WinRM; LLMNR/NBT-NS poisoning; PowerShell.
7. Collection: remote mailboxes, cloud storage, local data, staging; in Korea about 67,000 people's PII exfiltrated over HTTPS.
8. C2: multi-hop proxies, tunnelling, web protocols, rotating webhook-style callbacks.

### Hunting
1. Egress to api.anthropic.com, api.deepseek.com, open.bigmodel.cn, api.x.ai from web servers, jump hosts, build agents or any host not on the sanctioned AI list; DeepSeek and bigmodel.cn from servers strongest. (FBI)
2. Burst sequential requests on login, search and record-lookup endpoints of partner/employee portals. (FBI)

4. Every tenant that ever consented to ConnectWise apps: app-only and service-principal sign-ins by app ID since 1 Oct 2026; credential additions to apps, new owners, role assignments (self-assigned Global Admin), Conditional Access changes. (FBI; Microsoft)
5. Bulk Key Vault `SecretGet` across vaults by one principal; `FilterLogEvents` with secret-like patterns; ARM `validate` bursts. (behaviours FBI/Microsoft; queries ours)
6. Spray from 144.172.64.0/24 or single sources. (Microsoft)
7. Scan our own estate and third-party hosting for exposed ARTEX consoles. (ours)

- Least privilege for multi-tenant app permissions and consent; approval for high-risk certificate enrolment; Extended Protection on CA web interfaces.
- Rate-limit high-impact APIs, alert on sequential lookups, server-side authorisation, no stack traces to unauthenticated callers.
- Scan repos, pipelines and images for secrets; rotate.
- Preserve Entra, Purview, SIEM and Graph logs before removing anything. Keep ConnectWise connections disabled until restoration steps; do not delete enterprise apps as a first response.
- Report to IC3 citing 20261113-001.
