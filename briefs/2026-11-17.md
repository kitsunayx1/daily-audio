## 12. Deep dive: OPTIMJACK, the Optimizely Web supply-chain compromise (16 Nov 2026) [NEW]

**Primary:** Report URI (Scott Helme), 16 Nov 22:47 UTC: https://blog.report-uri.com/worlds-largest-brands-infected-with-malware-via-optimizely/
**Supporting:** https://www.stepsecurity.io/blog/optimjack-optimizely-hosted-scripts-crypto-clipper-card-skimmer ; https://itwire.com/business-it-news/security/optimizely-says-it-has-fixed-flaw-used-to-inject-malicious-scripts ; https://securityaffairs.com/203289/malware/optimjack-bbc-cnn-and-zoom-among-targets-of-optimizely-script-hijacking.html ; https://thecybersecguru.com/news/optimizely-supply-chain-attack-optimjack/ ; https://cybersecuritynews.com/optimizely-websites-hijacked/ ; https://gizmodo.com/sprawling-malware-attack-reportedly-affects-zoom-cnn-fox-news-peacock-and-170-others-2000840831 ; https://breachhistory.com/blog/optimizely-optimjack-skimmer-november-2026

### Why it matters for a global consulting firm
- One SaaS tag-delivery platform pushed a clipper, card skimmer, cookie/screenshot stealer and iOS exploit routing onto 178 organisations' sites, served from `cdn.optimizely.com` under Optimizely's own certificate.
- Victims: 32 finance, 23 tech/SaaS, 20 retail, 8 healthcare, 4 professional services (Freshfields, CohnReznick, Baringa, Cro Metrics).
- Two exposures: any site the firm runs or builds for clients that uses Optimizely or a similar experimentation/tag tool; and staff iPhones that visited affected sites on 16 Nov.
- Fourth "SaaS platform to every tenant" incident in a week (Fireworks, Barracuda, ConnectWise app trust, now Optimizely).

### Attribution and confidence
- Unattributed; financially motivated. Report URI links the injector (`webshell.lol`) to an actor seen on Turkish sites since September and abusing Kissmetrics, StorifyMe and Minute Media scripts 13–16 Nov. The Coruna loader is "byte-identical" to an October sample from a different campaign. Confidence in identity: low.

### Timeline (UTC, 16 Nov unless stated)
- 17 Sep: `webshell.lol` first seen. 9 Nov: iOS router domain registered.
- 02:21: last clean BBC snippet. **04:21: first Optimizely injection (BBC).** 05:23: `1688360.cc` registered.
- 08:10: first `track.js` (clipper). 11:20: Zoom snippet modified. 13:03–13:05: stolen crypto swept.
- **13:43: card skimmer added.** 17:13–17:57: Coruna iframe for iOS ≤18.6.
- 19:24–19:59: Report URI sweep finds 186 of 1,611 snippets infected; about $7,040 received.
- 20:40–21:10: mass clean-up. 21:52: one snippet left (TalkTalk). Smartsheet re-infected once.
- 17 Nov 01:02 UTC: Optimizely notice; code removed, accounts secured. Payload rebuilt 26 times.

### Initial access
- Optimizely: "an unauthorized party exploited a vulnerability in the Experimentation account signup flow"; vulnerable path blocked, tokens revoked, sessions ended. How that gave write access to other customers' projects is unexplained. Report URI ruled out CDN cache poisoning.

### Attack chain
1. Loader written into customers' `projectJS`; compiled and served by Optimizely (also via customers' own proxied snippets).
2. Silent try/catch; three variants: script tag, Base64 + `atob()`, inline `eval()` fallback.
3. Fetches `track.js` from `1688360.cc`.
4. Crypto clipper for 8 chains; card skimmer on first-party form fields via `sendBeacon` (cross-origin fields such as Stripe Elements not readable).
5. Non-HttpOnly cookies, URLs and `html2canvas` screenshots stolen.
6. iOS: `boot.js` routes iOS 13–17 to Coruna, 18.x to DarkSword; iOS 26 fingerprinted only.

### Hunting
- Inventory every Optimizely Web snippet served by the firm or clients, including self-hosted proxies; read `projectJS` and experiment custom code in full (Base64 variant evades string search): look for `atob(`, `eval(`, the markers above.
- Check snippet `Last-Modified`; ask Optimizely which projects changed and when.
