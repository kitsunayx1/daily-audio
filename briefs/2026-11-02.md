### Ivanti Connect Secure: UTA0576 chain [NEW]
- Fixed in **25.1.1.3** and **22.8R2.6**. Devices fully patched against CVE-2026-104935 on 13 Oct were still exposed to this chain.
- Exploited since at least 1 Oct (Defused) or 3 Oct (Volexity). The chain gives unauthenticated root.
- No web shell and no implant. The actor re-runs the three-stage chain for every command, tampers with logs and evades Ivanti's Integrity Checker Tool.
- Post-exploitation: steals stored credentials including LDAP domain credentials, dumps AD metadata, runs custom Kerberoasting and an LDAP tool that hunts LAPS passwords and BitLocker recovery keys, password sprays.
- Shadowserver: more than 5,000 exposed instances.
- **Action:** patch, then rotate credentials stored on the appliance and review AD for Kerberoasting and LAPS/BitLocker reads, because there is no implant to find.

## 5. AI attacks and trends

### VOLTA infostealer asks an LLM what each victim is worth [NEW, 31 Oct]
- Cisco Talos: a self-deleting Windows stealer (browser credentials and cookies, Slack/Discord/Telegram sessions, Microsoft OAuth tokens, SSH keys, gcloud and OpenVPN configs, wallets). Bypasses Chrome App-Bound Encryption by launching Chrome with `--headless`.
- Sends an "Identity_Report" to OpenRouter's chat API. Default model anthropic/claude-opus-4.6, with fallbacks; checks replies for refusals. The prompt casts the model as "a forensic intelligence analyst drafting a target assessment". Output goes to Telegram.
- Likely a builder sold as a service (Talos, unconfirmed). Compiled 17 Aug; first seen 11 Oct.
- IOC: SHA256 57ef4242666d78c50df145b34023df564f0fad38812d6a580e66433d427e2279; %APPDATA%\volta_debug.txt.
- Hunt: Chrome `--headless` spawned by non-developer processes; openrouter[.]ai traffic from unexpected binaries.
- Source: https://blog.talosintelligence.com/appraisal-by-ai-model-driven-victim-prioritization-in-the-volta-infostealer/

### CrowdStrike: VAPOR PANDA used ARTEX against 200+ organisations [OLDER, 29 Oct]
- New vendor research on the ARTEX story covered on 28 Oct. Activity from 17 Oct against at least 14 countries; post-exploitation confirmed at 9 organisations.
- Targets: foreign ministries (Latin America, Europe, Middle East), a Middle East interior ministry, 19 US pharma/semiconductor/defence/nuclear/finance organisations, telecoms in the US, Belgium and the Philippines.

## 12. Deep dive: the trojanised Claude Code extension on the Cursor Marketplace

**Why it matters:** a persistent SSH backdoor on developer laptops at any firm that lets engineers and consultants use Cursor. Uninstalling the extension leaves the backdoor in place.

### What happened
- A tampered `anthropic.claude-code` extension, **versions 2.1.312 and 2.1.313**, was published on the Cursor Marketplace under Anthropic's extension ID. The clean build is 2.1.314.
- Live on 29 Oct from about 09:27 to 20:35 UTC (02:27–13:35 PT), delivered by install or auto-update.
- Not affected: the Visual Studio Marketplace, npm `@anthropic-ai/claude-code` and Open VSX. Anthropic says its own systems were not compromised.
- Cursor took the marketplace down, rebuilt it, rotated keys and took the attacker server offline. How the attacker got publishing access is not public.
- Scale: at most 5,000 users, per THN citing Cursor; not on Cursor's notice as fetched.
- Attribution: none. Microsoft says its ATT&CK mapping "does not establish attribution".

### Behaviour
- About 66 injected lines of JavaScript run on module load, before the real extension code.
- **Recon:** hostname, user, OS, architecture, home and working directories, global git email, and the *names* (not values) of up to 40 environment variables matching KEY, TOKEN, SECRET, PASS, AWS or GCP.
- **SSH access:** appends an Ed25519 key with comment `svc-telemetry` to `authorized_keys` and tries to enable sshd.
- **Reverse tunnel:** writes the private key to a hidden temp file `.stk_` plus 10 hex characters and runs `ssh -N -R '*:0:localhost:22'` with host-key checking off, preferring autossh. On Windows a hidden PowerShell loop retries every 60 seconds.
- **Beacon:** recon sent over plain HTTP to port 8099, path /beacon.
- Cursor says missing admin rights blocked the tunnel on most Mac and Windows hosts, but the key and persistence were still written. No second stage observed.

### Persistence (per Microsoft)
- **macOS:** LaunchAgent `~/Library/LaunchAgents/com.apple.sysmond.plist`, plus `~/.config/.smt` and `~/.config/.smtk`.
- **Linux:** user crontab `@reboot`, plus `~/.config/.smt` and `~/.config/.smtk`.
- **Windows:** scheduled task "SysMon", `%USERPROFILE%\.config\smt.cmd` and `smtk`; fallback `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\sysmon.cmd`.

### IOCs (defanged)
- 134[.]209[.]82[.]225 (SSH and HTTP); hxxp://134[.]209[.]82[.]225:8099/beacon
- Key comment `svc-telemetry`; fingerprint SHA256:0Z6R+DF64Do2nwQic8a7kkfDLNNk4IiK+2U2Rci4htk
- ecb58cb29078d9646ad1dcdbe51526f2d9cfea06be5fb2ab183e8ecc3ab6bf15 (JavaScript entry point)
- 7e0a52885fadee05544a9e99eb18c792bec05900a5e1a66d68f8383decb0e278 (decoded tunnel private key)
- Filename pattern `.stk_[0-9a-f]{10}`
- Cursor lists per-platform VSIX hashes on its notice.

### Hunting
- Inventory Cursor extension directories for `anthropic.claude-code-2.1.312` or `-2.1.313`.
- Search every `authorized_keys` (including Windows `C:\ProgramData\ssh\administrators_authorized_keys`) for `svc-telemetry` or the fingerprint.
- ssh or autossh with `-R *:0:localhost:22` whose parent is Cursor, Code Helper or node; hidden PowerShell loops.
- New sshd enablement on developer laptops; any connection to 134.209.82.225 on 22 or 8099 since 29 Oct.
- Microsoft's KQL: DeviceFileEvents for `.smt`, `.smtk`, `smt.cmd`, `smtk`, `sysmon.cmd`, `com.apple.sysmond.plist`, `.stk_*`; ScheduledTaskCreated with "SysMon"; match on filenames because SHA-256 may be missing.

### Response
1. Identify hosts that installed or auto-updated the affected versions; preserve evidence; isolate hosts with loader execution.
2. Remove the `svc-telemetry` key, LaunchAgent, cron entry or task, startup file, `.smt`/`.smtk`/`smt.cmd`/`smtk` and `.stk_*` files, and related ssh processes. Cursor publishes remediate-macos.sh and remediate-windows.ps1; review before running.
3. From a clean device, rotate credentials present on affected hosts (cloud keys, git tokens, AI API keys). The environment-variable names tell you which secrets were there.
4. Policy: approved-publisher lists for Cursor and VS Code extensions, a cooldown on new versions, and block outbound SSH from developer endpoints where not needed.

### ATT&CK (Microsoft-provided)
- T1098.004 SSH Authorized Keys; T1572 Protocol Tunneling; T1053.003 Cron; T1053.005 Scheduled Task.
