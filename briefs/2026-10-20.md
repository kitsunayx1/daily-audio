## 12. Threat actor deep dive: ROMULUS, a ClickFix platform using fake ChatGPT GPTs

### Summary
- ROMULUS is a ClickFix delivery platform. It gets users to paste a PowerShell command themselves, then installs an unnamed remote-access trojan.
- Huntress has handled more than 40 incidents. Forescout has published parallel research.

### Lure
- Malicious ChatGPT Custom GPTs with names such as "Plus 5.6", plus sponsored Google search results.
- Both lead to a Google Sites page with a fake Cloudflare CAPTCHA. It tells the user to paste a PowerShell command into the Run box.

### Installation routes
1. **GUID-named MSI installers** that sideload a malicious DLL through a signed binary:
   - Canon COTFileReadApp loads ceiinfolog.dll, which loads rdCore.dll.
   - Stardock DeElevate64 loads DeElevator64.dll, which loads I++u.dll.
   - Siemens SiemensSoftwareCenter.exe loads archive.dll (CVE-2026-110936).
2. **LegionLoader:** an executable padded to 842 MiB to evade scanning, delivered in a 7z archive from orbitflownetwork[.]lol.

### The RAT
- Capabilities: screen capture, webcam, microphone, data from 17 browsers, and file search.
- C2 addresses are resolved over DNS-over-HTTPS.
- LegionLoader C2: smashshape[.]com (paths /nfront.php and /nback.php).

### Persistence
- A Run key re-created every 150 seconds.
- A scheduled task re-created every 875 seconds, named "Canon Configuration Reader" or "Stardock DeElevation Tool".
- **Kill the process first**, or it will put them back.

### IOCs
- **IPs:** 96.62.224[.]81, 86.109.75[.]7, 151.240.151[.]223, 23.94.145[.]224, 93.152.224[.]118, 2.27.248[.]127, 45.140.205[.]28, 96.62.218[.]59
- **Domains:** wizardexpensive[.]com, smashshape[.]com, orbitflownetwork[.]lol, gptverification[.]com
- **SHA-256:**
  - ISOSimple.msi: 6761aad48a3f987238994d92bca97e4b8550e0150607bd67b47b1b6366a371fc
