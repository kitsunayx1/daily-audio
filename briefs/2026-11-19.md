## 12. Deep dive: AuditTeam and OpsAgent, ransomware dressed as an audit [NEW]

**Primary:** Kaspersky GReAT (Vladimir Nestor), "The forced audit: how AuditTeam's OpsAgent framework masks ransomware as consulting", Securelist, 18 Nov 2026. https://securelist.com/auditteam-opsagent-forced-audit/122031/
**Secondary:** https://que.com/nvidia-on-a-ransomware-leak-site-40-5m-in-arrests-and-a-gang-selling-audits-ransomwares-wildest-24-hours-yet/

### Why it matters for a global consulting firm
- The ransom note is laid out as an **audit log** and demands an **"Audit & Consulting fee"** for a "vulnerability report". Victims or client crisis teams may confuse it with, or ask us to validate, a legitimate engagement; attackers could borrow real firm names.
- Global: observed in China, the Philippines, Senegal, Italy, Finland, Hong Kong, Russia; leak site claims Turkey, Thailand, Ukraine, Argentina, South Korea, Japan, Spain. "Dozens of organizations".
- Capable tooling: implant "comparable to Cobalt Strike", signed-driver EDR killer (about 220 processes), wiper-grade cryptor. Kaspersky says code patterns *suggest* LLM-assisted development (inference).

### Attribution and confidence
- Kaspersky: OpsAgent campaign attributed to **AuditTeam with high confidence** (note format, wording, Tor leak site, remediation-report model). No nation-state link; no aliases; first public mention March 2026 (dbdigest.com).

### Timeline (as published)
- 5 Jan 2026: campaign start (GitHub commit history). 29 Jan: C2 d19v1tntmz2i98[.]cloudfront[.]net added. 21 Feb: first leak-site victim. 10 Mar: Hong Kong organisation. Apr: C loader. Jun: .NET loader; Russian victim. 20 Aug: C2 d35htktbyt7nxc[.]cloudfront[.]net added. 24 Aug: 157.20.104[.]111 first seen. Sep: Rust loader. Oct: still active. Nov: GitHub repo removed. 18 Nov: report.

### Initial access
- **Not published.** No vector, no CVE.

### Attack chain
1. Loader: C (shellcode into `msiexec.exe`), .NET (`NtQueueApcThread` APC injection), Rust (in-process). Payload staged as `syscache.dat` in ProgramData/AppData cache paths.
2. C2 discovery: encrypted address from a public GitHub page (hxxps://github[.]com/RonaldCMalcolm1983/staticPage); CloudFront-fronted WebSocket over TLS; payloads over a named pipe.
3. OpsAgent / OpsAgent-rs (C++ rewritten in Rust): file ops, injection, getsystem, token theft, keylogging, screenshots, pass-the-hash, SOCKS pivoting, agent-to-agent links, shells.
4. Defence evasion: validly signed driver disguised as Beijing Jiangmin (KV) antivirus (`kvcore.sys`, port `\KvCorePortX0`) kills about 220 security, remote-access, logging and backup processes.
5. Impact: AES-CBC or ChaCha20 (X25519); kills DBs, stops backups, deletes shadow copies, wipes temp and overwrites deleted files.
6. Extortion: audit-log-style note with a Tor payment address.

### IOCs (as published, defanged)
- Domains: d19v1tntmz2i98[.]cloudfront[.]net ; d35htktbyt7nxc[.]cloudfront[.]net
- IP: 157.20.104[.]111
- GitHub C2 page: hxxps://github[.]com/RonaldCMalcolm1983/staticPage (removed)
- Stager MD5: d3e49dceb89a25f5da4ff0c42e996857 ; bd4c327ad208cb722ad25e43ea3f35fc ; 5d1425ab3dad1d2de053f69529d227e1 ; f0d5752054f6b7af1325ea340c4326d0 ; 83768e994c6bb72d0b430b98a71ec8d6
- Driver MD5: 109cdc24ccd4872a3e4bf6f2d4f3c3d4
- Paths: C:\ProgramData\Microsoft\Windows\Caches\syscache.dat ; %LOCALAPPDATA%\Microsoft\Windows\Caches\syscache.dat ; %LOCALAPPDATA%\Microsoft\CLR_v4.0\syscache.dat ; {modulepath}\syscache.dat ; {TempPath}\syscache.dat ; C:\Users\Public\kv_dbg.log ; C:\Windows\System32\drivers\kvcore.sys ; C:\Windows\Sysnative\drivers\kvcore.sys

### Hunting (ours; Kaspersky published no queries)
- Any `syscache.dat` in those paths; `kvcore.sys` or `kv_dbg.log`.
- Kernel driver installs signed as Jiangmin/KV on hosts that never ran it; `\KvCorePortX0` minifilter port.
- `msiexec.exe` with no installer parent, or with WebSocket/TLS to unusual `*.cloudfront.net` subdomains.
- Raw GitHub fetches from unusual user repos followed by CloudFront connections.
- Bursts of security, backup and remote-access process kills; EDR sensors going silent.
- `vssadmin`/`wmic shadowcopy delete`, backup service stops, DB kills in sequence.

### Mitigations (ours)
- Microsoft vulnerable-driver blocklist, HVCI/Memory Integrity, WDAC for kernel drivers; EDR tamper protection; immutable/offline backups; restrict `msiexec` egress.
- Brief client-facing and crisis-response teams: "audit fee" ransom notes are criminal extortion; watch for the firm's name in such notes.
