### WorkOS (US, enterprise SSO and identity SaaS): sales application breached with an AI framework [NEW]
- Security bulletin dated 2 Nov: unauthorised access to an internal sales application, identified 30 Oct.
- Exposed: CRM contacts, account histories, summaries and excerpts of sales calls, support discussions and **customer Slack conversations**, and product-usage metadata including directory and connection health.

## 12. Deep dive: CyberStrikeAI in the wild (Kaspersky, 2 Nov)

**Why it matters:** an off-the-shelf, open-source agentic framework took an exposed SQL Server to domain admin in days, with the hands-on phase under an hour. Database export was a main objective. Consulting firms run many project and client-facing database servers.

Source for this section unless noted: https://securelist.com/cyberstrikeai-attacks/121715/

### Summary
- CyberStrikeAI is an open-source, Go-based pentest platform with LLM orchestration and its own C2.
- The LLM runs on the attacker's server: it plans, picks tools and generates commands, with an optional human approving or correcting. The implant on the victim is a conventional agent with no AI, no API keys and no autonomous logic.
- Kaspersky's view: AI mainly lowered the skill barrier and sped up execution; the techniques are well known.
- Victims: education-sector organisations in several countries in Africa and Latin America (not named).

### Attribution and confidence
- No group named. **Low** confidence, because the tool is public and LLM-generated commands blur behavioural fingerprints.
- Weak signs of a Chinese-speaking operator: Chinese comments in scripts, use of dnslog[.]cn, C2 restarts mostly in UTC+8 working hours.

### Timeline
- Phase 1, manual: about one day of host and network reconnaissance and tool deployment, then a two-week pause.
- Phase 2, agent-driven: persistence and local reconnaissance in about 2 minutes; domain reconnaissance over about 5 hours; a pause of several days; then lateral movement, mass credential dumping and database export in no more than an hour.
- Agent deployment to domain admin: about 3–4 days. No calendar dates published.

### Initial access
- A compromised SQL Server (version 16.0.1000); first commands typed manually under sqlservr.exe. Entry method not described.

### Tooling
- Execution and persistence: Base64 PowerShell, schtasks and the Schedule.Service COM object (task named **SystemUpdate**), HKCU Run key; on Linux crontab @reboot and ~/.bashrc.
- Evasion: split and Base64-encoded scripts, certutil decoding, obfuscated SQL and LDAP queries.
- Discovery: net.exe, LDAP, WMI, Kerberoasting and AS-REP roasting queries, LAPS and Azure checks, AzCopy searches, Defender status checks.
- Credential access: registry hive dumps, comsvcs.dll MiniDump of LSASS, renamed mimikatz (wdiag2.exe) for DCSync and a Golden Ticket, DPAPI decryption of secrets in C:\ProgramData\dsn_line.txt.
- Privilege escalation: RogueWinRM.exe. Lateral movement: Impacket WMIExec, SMB, WMI, WinRM. Collection: SQL dumps, file scans, screenshots.

### C2
- HTTP/S, TCP or WebSocket polling with an **X-Implant-Token** header. Control panel uses a self-signed TLS certificate naming the framework. Payloads share identical build metadata.

### IOCs (as published; MD5)
- D726A8B4886C636F76CA6D30EF6A6FF4: c:\windows\temp\svchosts.exe (Windows beacon)
- 2770562d104391b92b42671c270079bb: c:\windows\temp\svcmon32.exe, also c:\programdata\svcmon32.exe
- 09e1da2afa1216ecc55648ec8e122d2a and 805B9E4AE74C903787416800999B8418: Linux beacon
- 29EFD64DD3C7FE1E2B022B7AD73A1BA5: C:\Windows\Temp\wdiag2.exe (mimikatz)
- 74F57B3E897A4960DCDD5B7E8A54F9DF: c:\rwx\RogueWinRM.exe
- 0BBD08AF95F877F1D568B03DE2EB76B4: c:\ProgramData\p1.ps1 (reverse shell to 185.186.245[.]144:5501)
- Network: 185.186.245[.]144 and fastcdn[.]bar (Windows C2); media.fastcdn[.]bar (Linux C2); 104.234.26[.]163 (delivery and Linux C2). dnslog[.]cn is legitimate; treat as context.
- Detection verdict: Backdoor.CyberStrikeAI.HTTP.C&C

### Hunting (built from Kaspersky's artefacts)
- sqlservr.exe spawning cmd.exe, powershell.exe, certutil.exe or reg.exe.
- Scheduled task "SystemUpdate" or new HKCU Run entries pointing to C:\Windows\Temp or C:\ProgramData; look-alike svchosts.exe or svcmon32.exe.
- rundll32 loading comsvcs.dll with MiniDump.
- X-Implant-Token in proxy or WAF logs; self-signed certificates naming the framework.
- DNS lookups for dnslog.cn from servers.
- Machine-speed bursts: many 4769/4768 Kerberos requests, 5145 share access and WMIExec-style `cmd /Q /c` within minutes; a reconnaissance burst, a days-long gap, then an under-an-hour burst of lateral movement and exfiltration.
- Kaspersky's rules use Windows events 4688, 4104, 4624, 4768, 4769, 5145 and auditd execve/openat.
