# Morning Signal

Daily threat-intelligence audio brief built from public reporting.

- Feed: `feed.xml` (served via GitHub Pages)
- Episodes: `episodes/YYYY-MM-DD.mp3` + `.json` metadata
- Written briefs with all sources: `briefs/YYYY-MM-DD.md`, organisation table as `briefs/YYYY-MM-DD-orgs.csv`, spoken script `briefs/YYYY-MM-DD-script.txt`
- Tools: `tools/tts.py` (local Kokoro TTS -> MP3), `tools/build_feed.py` (rebuild RSS)
